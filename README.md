# Prompt Forge · 提示锻造

一个**单文件、离线可用**的 AI 绘图提示词工作台，外加 Android 客户端：同一个 App 里「挑标签 → 写提示词 → 下模型 → 出图」。

## 关于

写提示词这件事的麻烦不在「不会写」，而在「要记的东西太多」：几千个 Danbooru 标签、几百个角色、十几种底模各自的词序和权重习惯、每家云服务商的参数默认值。Prompt Forge 把这些收进一个页面，点标签就能拼句，选模型就自动配对参数，出图链路内置，不用在四五个网站之间来回复制粘贴。

所有数据只存在本机（浏览器 localStorage / App 沙箱），不联网也能用；要出图时才走云端 API 或本机引擎。

## 是什么

最初是一个 1MB 的单文件 HTML 工具。Android 版是它的外壳：内嵌同一份 HTML，外加模型下载与本机生图引擎的通道。

## 主要能力

- **标签库 3400+**：人物、角色、构图、光影、画风、镜头、材质等维度分组，中文 / 英文 / 拼音都能搜，点一下直接拼进提示词。
- **三套提示词体系**：Anima（标签流）、MOSS-Image（自然语言）、Krea2（散文），切换时自动换算词序与负向词。
- **一键负向 + 本地扩写**：按当前底模给一套负向；一句中文短句可离线扩成完整正向标签流，不联网、不花钱。
- **云端多家服务商**：OpenAI 兼容、Stability、SD WebUI 等接口一处切换，填地址和 Key 即可出图。
- **模型库**：26 个端侧模型清单（SD1.5 / SDXL），内置直链，支持下载 / 暂停 / 续传 / 删除，进度条带实时速度，可切国内镜像或国外直连。
- **纯本地存储**：配置、历史、自定义标签都在本机，卸载会清空，重要配置用「导出 / 导入 JSON」备份。

## 本机出图现状

| 环节 | 状态 |
| --- | --- |
| 界面与标签库 | 可用 |
| 云端 API 出图 | 可用 |
| 模型下载（暂停 / 续传 / 删除） | 可用 |
| native 引擎编译（sd.cpp → `libpfengine.so`） | 构建链就绪 |
| 本机真正出图（采样 + 像素回传） | 未接入 |

即：现在的 APK 能进界面、能下模型、能用云端出图；本机出图会提示引擎未接入。

## 安装

从 Releases 下载最新的 `app-debug.apk`，手机直接安装（需允许「安装未知来源应用」）。

系统要求：Android 8.0（API 26）及以上，arm64-v8a。

## 构建

仓库里只保留一份 30 行的 workflow，真正的编译逻辑在云端脚本里（手机端不必再粘贴长文件）。

流程：装 JDK17 → SDK/NDK/CMake → 拉源码包 → 编译 stable-diffusion.cpp → 链接 `libpfengine.so` → Gradle 打包 → 发布到 Releases。

每次构建的日志摘要会推到 `ci-report` 分支的 `ci/last.txt`，方便在手机上直接看失败原因。
